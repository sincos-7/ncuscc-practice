ncuscc-practice
这个仓库存放的是C/C++ 方向的练习代码和实践记录。

项目介绍：
  在Linux环境，通过命令行操作，完成C/C++方向的练习，内容有基础语法、STL容器使用、环形缓冲区实现、多文件 CMake 构建、指针内存问题排查，以及多线程快速排序的简单实现。所有代码均在Ubuntu 22.04环境下编译通过。

仓库结构：
  所有题目源码统一放在 src 目录下，每一关一个文件夹，完成顺序是文件夹名字中的01、02等，根目录下的 PDF是实践报告，包括环境搭建、问题排查和个人感悟。

环境要求：
  运行和编译这些代码需要Linux环境，使用的是Ubuntu 22.04，通过命令行使用g++编译器编译，多文件题目安装并使用了cmake构建工具。

编译运行方式：
   单文件题目进入对应文件夹后，执行g++ -std=c++17 -Wall -Wextra -o main main.cpp进行编译，编译完成后运行./main执行程序。多文件题目在对应目录下执行cmake -B build，进入build目录后运行make完成构建。
